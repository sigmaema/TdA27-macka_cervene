# Javascript React Frontend Template (English)

Basic React (JavaScript) template for displaying, adding, editing, and deleting products in a school cafeteria.

## Running the app

The application requires a running backend API at `http://localhost:8080`.

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

## File Structure

- `src/api.js` - Communication with the backend (GET, POST, PUT, DELETE).
- `src/App.jsx` - The main component maintaining the application state.
- `src/ProductForm.jsx` - Form for adding and editing.
- `src/ProductTable.jsx` - Rendering the list of products.
- `src/index.css` - Basic styling.

# Javascript React Frontend Template (Čeština)

Základní React (JavaScript) šablona pro zobrazení, přidávání, úpravu a mazání produktů ve školním bufetu.

## Spuštění

Aplikace vyžaduje běžící backend API na adrese `http://localhost:8080`.

1. Instalace závislostí:
```bash
npm install
```

2. Spuštění vývojového serveru:
```bash
npm run dev
```

## Struktura souborů

- `src/api.js` - Komunikace s backendem (GET, POST, PUT, DELETE).
- `src/App.jsx` - Hlavní komponenta udržující stav aplikace.
- `src/ProductForm.jsx` - Formulář pro přidání a úpravu.
- `src/ProductTable.jsx` - Vykreslení seznamu produktů.
- `src/index.css` - Základní stylování.
